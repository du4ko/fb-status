# Статус на сатиричните страници

Статичен сайт + бот, който на всеки 30 минути проверява дали Facebook страниците от `pages.json` са публично достъпни и пази история на промените. Работи безплатно на GitHub (Actions + Pages), без собствен сървър.

## Файлове

| Файл | Какво прави |
|---|---|
| `pages.json` | Списък с медиите и всичките им страници (стари и нови) — **тук редактираш** |
| `check.mjs` | Скриптът за проверка (Node 20, без зависимости) |
| `.github/workflows/check.yml` | Пуска проверката на всеки 30 мин. и записва резултата |
| `index.html` | Самият сайт — чете `pages.json` и `data/*.json` |
| `data/status.json`, `data/events.json` | Генерират се автоматично |

## Пускане (≈10 минути)

1. Създай **публично** repo в GitHub (напр. `fb-status`) и качи всички файлове, включително папката `.github`.
2. **Settings → Actions → General → Workflow permissions** → „Read and write permissions" → Save.
3. **Settings → Pages** → Source: „Deploy from a branch", branch `main`, папка `/ (root)` → Save.
4. **Actions → „Проверка на страниците" → Run workflow** за първа проверка.
5. Сайтът е на `https://<потребител>.github.io/fb-status/`. По желание — собствен домейн в Settings → Pages.

## Добавяне на страници

Когато медия пусне нова страница след сваляне, добави я **най-отгоре** в `pages` на съответната медия:

```json
{
  "id": "ime-na-mediata",
  "name": "Име на медията",
  "description": "Кратко описание",
  "pages": [
    { "url": "https://www.facebook.com/nova.stranica", "added": "2026-10-25" },
    { "url": "https://www.facebook.com/stara.stranica", "added": "2026-09-10", "override": "down", "note": "Свалена на 24.10" }
  ]
}
```

- `override: "down"` / `"up"` — ръчно задаване, когато автоматиката не може да определи статуса (Facebook често показва екран за вход вместо страницата).
- `note` — свободен текст, показва се под страницата.

Редакцията може да става директно в GitHub през браузъра (молив → Commit) — сайтът се обновява за минута.

## Как се определя статусът

- **Активна** — страницата връща публични метаданни (`og:title`).
- **Недостъпна** — HTTP 404/410 или екран „Съдържанието не е налично". Нужни са **2 поредни** такива резултата, за да няма фалшиви тревоги.
- **Неясно** — Facebook е върнал вход/ограничение; запазва се последният потвърден статус.

Важно: „недостъпна" значи, че страницата не се зарежда публично — не доказва *кой* я е премахнал. На сайта това е изрично написано; препоръчвам да се формулира така и в публикации, за да не може да се оспори.

## Локален тест

```bash
node check.mjs
npx serve .   # после отвори http://localhost:3000
```

## Ограничения

- Facebook понякога блокира заявки от GitHub сървъри (резултат „Неясно"). Ако стане често: увеличи паузата в `check.mjs`, намали честотата в `check.yml` или ползвай `override`.
- Скриптът гледа само публичния статус — не влиза в акаунт и не събира данни за хора.
